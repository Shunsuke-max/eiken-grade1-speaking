# EIKEN Grade 1 Speaking — 300 Phrases / 900 Examples

英検1級のスピーキング対策用に作成した、**300表現 × 各3例 = 900例文**の非公式学習サイトです。

## Features

- 300の再利用しやすい英語表現
- 各表現につき3つの例文、合計900例文
- 全例文に日本語訳
- 表現番号・英語・日本語による検索
- 30カテゴリーで絞り込み
- 優先30表現のみを表示
- 日本語訳の表示 / 非表示
- ランダム出題
- スマートフォン対応
- 印刷用レイアウト
- 外部ライブラリ・CDN不要

## Local preview

`index.html` をブラウザで直接開くだけでも利用できます。

ローカルHTTPサーバーで確認したい場合は、リポジトリのディレクトリで次を実行できます。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。


## Content note

収録英文は学習用の作例です。公式の模範解答や、実在の事例・統計の引用ではありません。個人の経歴や経験を述べる例文は、実際のスピーキングでは自分自身の内容に置き換えてください。

このリポジトリは英検の**非公式学習教材**であり、実施団体との提携・承認関係はありません。

## Optional workbook

`eiken_grade1_300phrases_900examples.xlsx` には、同じ900例文を練習状況つきで管理できるExcel版を収録しています。Webサイトの動作には不要なので、Webサイトの実行には不要なので、必要がなければ同ファイルを削除できます。

## 学習と復習機能

各表現の上部に以下のボタンを追加しています。

- **英文を隠して練習**：英語表現と英文を隠し、日本語から英語で言えるか確認します。もう一度押すと表示されます。
- **例文①を聴く**：ブラウザの音声合成機能で最初の例文を読み上げます。声や音質は端末・ブラウザによって異なります。
- **要復習 / 習得済み**：学習状況をブラウザの `localStorage` に保存します。選択済みのボタンを再度押すと「未学習」に戻せます。
- **学習状況で絞る**：未学習・要復習・習得済みの表現を抽出します。既存の検索やカテゴリー絞り込みと組み合わせられます。
- **要復習から1つ練習**：要復習に登録した表現をランダムに表示します。

学習記録はこのブラウザだけに保存されます。**端末間同期、クラウドへのアップロード、厳密な間隔反復（SRS）は未実装**です。シークレットブラウズやサイトデータ削除によって学習記録が失われる場合があります。

## 開発・確認

```bash
node --check study.js
node --test tests/content.test.mjs
```

上記の確認では300表現・900例文・30カテゴリーとアセットの参照を検証します。実際の読み上げ音質、端末ごとの動作、レスポンシブ表示は別途ブラウザで確認してください。
